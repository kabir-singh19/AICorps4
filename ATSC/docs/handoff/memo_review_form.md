# Blind memo grading (FSR 3.2.1.16, EVP 4.3.2, 404 work)

**Protocol (EVP 4.3.2):** 15 flagged sites chosen at random, stratified by site type (segments, signalized and unsignalized intersections). For each site there are two memos in the same template: the ATSC memo and a consultant-style reference memo (from the CSAP recommendations where the CSAP covers the site, otherwise written by a team member without AI help). They are labeled X and Y at random. The reviewer (a TTI safety researcher or equivalent) does not know which one is AI.

**Pass:** ATSC mean ≥ 3.5 of 5, and no more than 0.5 point below the reference mean.

**Team prep (before the reviewer sees anything):** draw the 15 sites with a recorded seed, write the reference memos, strip model names, timestamps and run IDs from both memos, assign X/Y with a coin flip, and keep the key in a file the reviewer does not get.
