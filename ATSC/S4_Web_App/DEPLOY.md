# Deploying the ATSC web app

The deployed app is one container: FastAPI serves the built React frontend and the REST API
(IF-08) from a read-only copy of one run artifact. It needs no database and no LLM key; memos are
generated offline by S3 (`make memos`) and shipped inside the artifact.

## What goes into the image

| Path in the image | Source | Built by |
|---|---|---|
| `/app/frontend/dist` | `frontend/` (Vite build) | Dockerfile stage 1 |
| `/app/backend/app` | `backend/app` | copied |
| `/app/backend/data/artifacts/<run_id>/` | `integration/artifacts/<run_id>/` without `models/` | `make web` (rsync), committed |
| `/app/backend/data/published/` | two labeled synthetic example runs (shown only when no real run exists) | committed |

At startup the adapter checks every bundled file against the SHA-256 values in `manifest.json`; a
run with a mismatch is not served and `/api/v1/health` reports `degraded`.

To publish a new run: `make model memos web RUN_ID=<new id>`, commit
`S4_Web_App/backend/data/artifacts/`, push, and redeploy. Rolling back is a revert of that commit.

## Render

The Blueprint is `ATSC/S4_Web_App/render.monorepo.yaml` (`rootDir: ATSC/S4_Web_App`, Docker,
health check `/api/v1/ready`).

1. In the Render dashboard: **New > Blueprint**, connect `kabir-singh19/AICorps4`, branch `main`,
   Blueprint path `ATSC/S4_Web_App/render.monorepo.yaml`.
2. Apply. Render builds the Dockerfile and sets `ATSC_ENV=production`, a generated
   `ATSC_SESSION_SECRET`, and `ATSC_AI_ENABLED=false`.
3. Check `https://<service>.onrender.com/api/v1/health`: `status: ok`, `artifact_runs: 1`,
   `assistant_enabled: false`.

Creating the service needs a Render account login. No Render credentials were available to the
build machine, so the service has not been created from here (see "Status" below).

## HTTPS only

Render terminates TLS and forwards `X-Forwarded-Proto`. With `ATSC_ENV=production` the app:

- answers any request that arrived over plain HTTP with `308` to the `https://` URL;
- sends `Strict-Transport-Security: max-age=31536000` on HTTPS responses;
- sends a Content-Security-Policy that allows scripts only from its own origin and map tiles only
  from `tile.openstreetmap.org`.

## Keys never reach the browser (FSR 3.2.4.5)

The frontend calls only same-origin `/api/v1` endpoints. The image contains no LLM key; the chat
page is behind `ATSC_AI_ENABLED` (off) and its navigation entry is hidden unless
`/api/v1/health` reports `assistant_enabled: true`. The Playwright suite checks that no served
HTML or JavaScript contains a key-like string.

## Endpoints served from the artifact

| Endpoint | Returns |
|---|---|
| `GET /api/v1/health`, `/api/v1/ready` | status, artifact run count, assistant flag |
| `GET /api/v1/runs` | run summaries (run_id, created, code_version, data_versions, memo counts) |
| `GET /api/v1/sites?run_id=&bbox=&flagged=` | GeoJSON FeatureCollection, ICD Table 9 properties (gzip) |
| `GET /api/v1/sites/{site_id}?run_id=` | attributes, prediction (mu, k, eb_weight, n_eb, p_fsi, fsi_rate, rank), crash history by year, top 5 SHAP factors, memo status |
| `GET /api/v1/sites/{site_id}/memo?run_id=` | memo JSON (`draft`, `blocked`, `pending` or `none`) |
| `GET /api/v1/sites/{site_id}/memo.pdf?run_id=` | memo PDF (IF-11); `409` for a blocked memo, `404` if none |
| `POST /api/v1/sites/{site_id}/memo` | `503 llm_unavailable`: memos are generated by the S3 batch, not on the web host |
| `GET /api/v1/backtest?run_id=` | every scenario: capture, 95% CI, flagged miles and share, paired differences |
| `GET /api/v1/export/sites.csv?run_id=&flagged=` | RFC 4180 CSV, Table 9 columns first (cells starting `= + - @` are prefixed with `'`) |
| `GET /api/v1/export/sites.geojson?run_id=&flagged=` | RFC 7946 GeoJSON |
| `GET /api/v1/openapi.json` | OpenAPI document |
